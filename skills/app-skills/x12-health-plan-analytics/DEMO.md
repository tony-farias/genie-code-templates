# X12 Health Plan Analytics Demo

## Outcome

The demo discovers X12 sources in Unity Catalog, validates a confirmed source without printing payloads, parses 837P, 835, and 834 transactions with the Databricks X12 parser, and publishes curated health-plan analytics to a fixed Databricks App and Genie Space.

## Deployment boundary

- Workspace profile: supplied at deployment time.
- Source: a confirmed Unity Catalog table or volume-backed table.
- Test source: deterministic fictional X12 records generated by this repository.
- Raw and parsed JSON: restricted Bronze and Silver tables.
- App and Genie: approved Gold tables and an aggregate data-quality table only.

## Architecture

```text
Unity Catalog discovery
  -> confirmation manifest
  -> Bronze raw lineage
  -> X12 parser + quarantine
  -> normalized Silver tables
  -> de-identified Gold analytics
       -> fixed React/FastAPI App
       -> deterministic Genie Space
```

The parser is pinned to commit `ac6d84d3f322310816a55a43569242afe295b4c5`. The classic job cluster is intentional: the upstream parser's final JSON materialization uses RDD APIs that are unavailable through serverless Spark Connect.

## Visual contract

The App is a versioned reconstruction of the original FWA Shield workbench. Its Dashboard, SIU Workbench, provider drilldowns, deterministic letter workflow, and embedded Genie experience live under `assets/app-template` and are copied unchanged for every deployment. Only `app-config.json` is generated. `DESIGN.md`, the App contract, the source lock, and approved screenshots prevent per-run design drift.
